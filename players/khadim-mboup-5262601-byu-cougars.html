RPR

RPR 1.98. Formula: (ORtg - 100) × possessions used per game / 100 + 0.5 × (AST - TO) per game + (STL + BLK) per game + 0.25 × REB per game. That is 91.0 ORtg, 4.6 possessions used per game, 0.4 AST, 0.8 TO, 1.2 STL+BLK, 5.6 REB per game.

This is the v1 RPR, uncentered: an average rotation player scores about +1 to +3, so almost everyone gets some credit just for playing. The NBA site's RPR v1.2 recenters the counting terms on league averages so an average player scores about 0; that recentering has not been applied here, so the two sites' RPRs are not on the same scale.
